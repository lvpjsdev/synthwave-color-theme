# Min Darker Theme Design Tokens

Design system based on [Min Darker](https://github.com/GmsGarcia/min-darker) VS Code theme.

## About

A minimal dark theme for Visual Studio Code with low contrast and clean aesthetics.

## Color Palette

| Name | Token | HEX |

## Design Philosophy

- Minimal contrast for reduced eye strain
- Dark backgrounds for long coding sessions
- Subtle color differentiation
- No neon glow effects
