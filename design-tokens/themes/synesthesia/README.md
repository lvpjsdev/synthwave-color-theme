# Synesthesia Theme Design Tokens

Design system based on [Synesthesia Synthwave](https://github.com/stackmason1/synesthesia-theme) VS Code theme.

## About

4 dark themes inspired by synesthesia (when people literally see sound) and 80s retrofuturism. Every variant riffs on a different musical genre.

## Theme Variants

The original VS Code theme includes 4 variants:
- **Synthwave** — Main, classic neon
- **Dawn** — Early morning riffs, warm & optimistic
- **Dusk** — Deep purple night, saturated, moodier
- **Midnight** — 3AM-Club Vibe, super-dark, ultra-glow
